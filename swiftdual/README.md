# SwiftDual — official multi-account hub (v1.0)

The honest version of what Dual Space promises: instead of the fake-environment trick (which cannot run on Android 14 Go and gets apps banned), SwiftDual finds every app on your phone that has **built-in second-account support** and gives you one-tap access plus the exact steps for each.

Shows: WhatsApp, Instagram, Facebook, Messenger, Telegram, X (Twitter), TikTok, YouTube, Gmail.

- If an app is installed → OPEN + APP INFO buttons and step-by-step "add account" instructions
- If not installed → dimmed with its package name
- Includes a card explaining the different-IP setup (any VPN app) and pointing heavy-duty cloning to SwiftClone (device-owner route)

No risky permissions beyond being able to see installed apps. No hidden system APIs, nothing that can break or flag your accounts.

## Rebuild
`./build.sh` (same Swift toolchain as SwiftBoost/SwiftClone/SwiftPower/SwiftCut).
